# CanchaLibre – Sports Venue Booking & Management System
> **Academic Note:** Final capstone project developed for *1INF30: Advanced Programming / OOP* at Pontificia Universidad Católica del Perú (PUCP), Semester 2026-1. Final Mark: 19/20.

A desktop management platform designed to streamline sports field scheduling, customer reservations, and venue administration. 

---

## Overview

Managing sports facilities involves handling concurrent reservations, avoiding scheduling conflicts, and maintaining accurate administrative records. **CanchaLibre** provides a modular software solution integrating high-performance data processing with an intuitive interface to handle time-slot reservations, client profiles, and facility operations.

---

## Key Features

- **Automated Scheduling Engine:** Resolves time-slot availability and prevents double-booking through custom validation algorithms.
- **Reservation Lifecycle Management:** Supports booking creation, updates, cancellations, and status tracking.
- **User & Venue Administration:** Categorizes fields by sport, pricing tiers, and maintenance schedules.
- **Structured Data Persistence:** Serializes and manages persistent venue and customer transaction records.

---

## Technical Stack & Architecture

- **Languages:** C++ & Java
- **Core Principles:** Object-Oriented Programming (OOP), SOLID design principles, separation of concerns (Model-View-Controller / layered architecture).
- **Techniques:** Dynamic memory management, custom data structures, search and sorting algorithms, file I/O for data persistence.
